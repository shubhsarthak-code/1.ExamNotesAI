# 🚀 AI Exam Notes Generator

An intelligent note-generation platform that transforms any academic topic into structured, exam-ready study material using Google's Gemini AI.

Instead of searching through multiple websites or creating notes manually, students can generate concise, organized, and revision-friendly notes within seconds.

---

# ✨ Why this Project?

Preparing notes before exams often requires hours of reading and summarizing.

This project leverages Large Language Models (LLMs) to automate that process by generating:

- Structured notes
- Key concepts
- Revision summaries
- AI-generated diagrams
- Visual learning aids

The goal is to help students focus more on learning rather than note preparation.

---

# 🎯 Key Features

### 📖 Smart Note Generation

Generate comprehensive notes for any topic using AI.

### 🎓 Academic Customization

Customize notes based on:

- Class Level
- Subject
- Exam Type

### ⚡ Revision Mode

Generate short revision notes for quick exam preparation.

### 📊 Visual Learning

Automatically generate:

- Flowcharts
- Tables
- Concept diagrams

### 📄 PDF Export

Download generated notes as printable PDFs.

### 📱 Responsive Interface

Works seamlessly across desktop and mobile devices.

# ⚙️ Getting Started

## Clone Repository

```bash
git clone https://github.com/shubhsarthak-code/1.ExamNotesAI.git
```

## Install Dependencies

Frontend

```bash
cd client
npm install
```

Backend

```bash
cd ../server
npm install
```

## Run Application

Backend

```bash
cd server
npm run dev
```

Frontend

```bash
cd client
npm run dev
```
